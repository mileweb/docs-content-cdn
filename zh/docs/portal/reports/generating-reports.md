# 生成报表

CDN Pro 提供报表功能，使您能够分析加速项目的流量、识别随时间变化的趋势，并找出访客最可能访问您网站的时间点。

报表在报表页面生成。要显示此页面，请在左侧导航栏中点击**报表**，然后选择**数据图**。

下图显示了页面上的关键元素，图后的表格对它们进行了说明。

<p align=center><img src="/docs/resources/images/reports/reports-w-numbers.png" alt="report page" width="650"></p>

| **编号**   | **说明**                                                                                           |
| :----------: | --------------------------------------------------------------------------------------------------------- |
| 1            | 指定报表类型、日期范围以及适合您要生成的报表的其他参数。               |
| 2            | **查询报表**按钮用于生成由报表参数定义的报表。        |

## 支持的报表类型

支持以下报表类型：

| **报表**            | **说明**                                                   |
| --------------------- | ----------------------------------------------------------------- |
| 流量        | 报告边缘与源站流量。                                 |
| 带宽     | 报告边缘与源站流量带宽。折线表示 CDN Pro 服务器的边缘流量、源站服务器的流量以及缓存命中率。垂直（Y）轴显示带宽和命中率，水平（X）轴显示时间。缓存命中率的计算方式为（边缘流量 - 源站流量）/ 边缘流量。     |
| 请求数              | 报告对加速项目文件发出的请求。折线显示发往 CDN Pro 边缘服务器的请求数、发往源站服务器的请求数以及缓存命中率。缓存命中率的计算方式为（边缘请求数 - 源站请求数）/ 边缘请求数。              |
| 状态码详情   | 报告返回的 HTTP 状态码的百分比。例如，状态码 200 表示请求成功。 |
| 源站状态码详情   | 报告发往源站服务器的请求中返回的 HTTP 状态码的百分比。例如，状态码 200 表示请求成功。 |
| 回源快速通道流量   | 报告使用 {{title}} 的<a href="/zh/cdn/docs/edge-logic/supported-directives#origin_fast_route">快速通道功能</a>以使连接更快、更可靠的源站流量。 |
| 回源快速通道请求数   | 报告使用 {{title}} 的<a href="/zh/cdn/docs/edge-logic/supported-directives#origin_fast_route">快速通道功能</a>以使连接更快、更可靠的源站请求数。 |
| CPU时间| 报告每个时间间隔内为您的加速项目提供服务所消耗的 CPU 时间。您可以在**秒**和**核心数**之间切换单位。例如，如果在 5 分钟间隔内报告了 3000 秒的 CPU 时间，则表示您的加速项目在该时间段内平均占用了 10（=3000 秒/5 分钟）个物理 CPU 核心。                               |
| 调度域名DNS请求数| 显示一段时间内向您的[调度域名](</docs/portal/traffic-management/creating-edge-hostname.md>)发出的请求数。                               |
| 边缘流量汇总| 汇总边缘流量。将鼠标悬停在饼图的扇形上会显示流量量的详细信息。                              |
| 请求数汇总| 按组汇总所有请求，包括边缘请求和快速通道请求。将鼠标悬停在饼图的扇形上会显示请求的详细信息。                              |
| CPU时间汇总| 按组汇总 CPU 时间，包括边缘 CPU 时间总量和中间层 CPU 时间总量。将鼠标悬停在饼图的扇形上会显示 CPU 时间的详细信息。                              |

**注意：**当您使用**报表类型**下拉列表在这三个报表之间切换时，您为边缘流量汇总、请求数汇总或 CPU时间汇总报表所做的选择会保留。

## 生成报表

1. 在左侧导航栏中，点击**报表**，然后选择**数据图**。 
2. 填写报表页面中的字段。

<p align=center><img src="/docs/resources/images/reports/reports-wo-numbers.png" alt="report page" width="650"></p>

| **字段**      | **说明**                                       |
| --------------- | ----------------------------------------------------- |
| 报表类型     | 选择要生成的报表类型。       | 
| 报表范围        | 如果您是拥有子客户账号的代理商，请选择此报表覆盖的账号。 <li><strong>仅此账号</strong>。（*默认*）</li><li><strong>仅子客户账号</strong>。</li><li><strong>此账号 + 子客户</strong>。|
| 日期范围      | 选择报表的开始和结束日期及时间。 |
| 粒度 | 对于除边缘流量汇总外的所有报表，选择返回数据的粒度。 <li><strong>5 分钟</strong>。（*默认*）</li><li><strong>1 小时</strong>。</li><li><strong>1 天</strong>。</li><li><strong>1 个月</strong>。</li>|
| 加速域名       | 对于除调度域名DNS请求数外的所有报表，选择在您的加速项目中定义的一个或多个加速域名。 <br><br>**提示：**如果您选择两个或更多加速域名，可以通过点击下拉列表底部的**+将所选加速域名保存为组**将它们保存为一个组。下次要使用相同的加速域名时，只需选择该组，而无需逐个选择加速域名。下拉列表顶部**组**旁边的向下箭头允许您将组导出为 CSV 文件。         |
| 调度域名       | 对于调度域名DNS请求数报表，选择一个或多个调度域名。         |
| 协议        | 对于除调度域名DNS请求数外的所有报表，选择要报告的基于协议的数据流量。 <li><strong>全部</strong> = 报告 HTTP 和 HTTPS 流量。（*默认*）<li><strong>HTTP</strong> = 仅报告 HTTP 流量。<br><li><strong>HTTPS</strong> = 仅报告 HTTPS 流量。         | 
| 节点组        | 除调度域名DNS请求数报表外的所有报表都支持按节点组筛选。默认情况下，包含所有节点组的数据。要选择特定节点组，请从可用选项中选择。|
| 按指定字段汇总       | 如果**报表类型**设置为**边缘流量汇总**、**请求数汇总**或 **CPU时间汇总**，请使用此字段根据以下一个或两个选项对结果进行分组。 <li><strong>无</strong>。</li><li><strong>加速域名</strong>。</li><li><strong>节点组</strong>。</li><li><strong>客户ID</strong>。</li> |

3. 点击**查询报表**按钮生成报表。
4. 报表生成后，您可以：

<ul><li>将鼠标悬停在报表中的数据点上以查看详细信息。<br>
<li>在图表上拖动以放大区域，然后使用<strong>Reset zoom</strong>按钮返回默认缩放级别。<br>
<li>使用报表右上角的三个垂直按钮，以逗号分隔值（CSV）格式下载原始数据、创建注释（见下文）或隐藏注释。
<li>使用图表下方的“时间范围内流量”字段获取流量报表某个时间范围内的流量。</ul>

<p><img src="/docs/resources/images/reports/download-options-icon.png" alt="dload options" width="225"></p>

## 创建注释

生成报表后，您可以创建文本注释来标记与发往您加速域名的流量相关的事件。

1. 点击报表右上角的三个垂直按钮，然后选择**创建注释**。
2. 填写“创建注释”对话框中的字段。

   <p align=center><img src="/docs/resources/images/reports/create_annotation.png" alt="report page" width="650"></p>

| **字段**      | **说明**                                       |
| --------------- | ----------------------------------------------------- |
| 注释类型 | 选择要添加的注释类型。<ul><li> <strong>客户端</strong> = 影响客户端的事件，例如热门游戏的发布。</ul></li><ul><li><strong>配置</strong> = 与配置更改相关的事件。</ul></li> **注意：**由 {{title}} 创建以指示运营事件的注释也可能会出现在您的报表中。  |
| 时间            | 选择表示注释生效时间的 RFC 3339 日期。 |
| 描述        | 输入关于事件的描述。描述会显示在报表中。 
| 加速域名       | 选择一个或多个加速域名。您可以使用通配符域名，例如 <strong>*.abc.com</strong>、<strong>\*.com</strong> 或 <strong>\*</strong>。如果留空，注释将应用于所有加速域名。 |
| 服务器区域  | 选择受事件影响的一个或多个 CDN Pro 服务器区域。         |
| 客户端区域  | 选择受事件影响的一个或多个最终用户区域。         |

3. 点击**创建**。
   
创建注释后，您可以通过点击报表右上角的三个垂直按钮并选择**隐藏注释**或**显示注释**来隐藏或重新显示它们。
